# Objects the player needs to recognize

99 shared semantic object types, mapped across all 276 supplied games. The same object may carry multiple roles. These are game-family inventories; a particular level or frame may use only a subset.

Recognize identity, shape, position and behavior together. Color is game-specific. Also retain orientation, size, visibility, selected state, connections, containment, ownership, counters and relevant history. A closed door is a state of a door; a red crate is a crate with a color attribute.

Sources: the 276 identical Python modules from games.zip / games_w_desc.zip, their supplied metadata, recovered game logic, and level snapshots. Hidden/internal identifiers are evidence for the analysis; they are not observable features available to a player.
